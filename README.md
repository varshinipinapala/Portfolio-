# Varshini Pinapala — HR Management Portfolio

A responsive, three-file personal portfolio website designed around Human Resource Management, people analytics and postgraduate-study preparation.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, visual system, animations and mobile styles
- `script.js` — mobile navigation, scroll progress and reveal-on-scroll effects

## Run locally
1. Download and extract the ZIP.
2. Keep all three files in the same folder.
3. Double-click `index.html` or open it in Chrome, Edge or Firefox.
4. Internet access is needed for the Google Fonts; the site itself works without them using fallback fonts.

## Publish with GitHub Pages
1. Create a repository on GitHub (for example, `hr-management-portfolio`).
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages settings.

## Personalise before publishing
- Check your phone number and email address in `index.html`.
- Confirm the GitHub and LinkedIn profile URLs.
- Add project screenshots, dashboard images or downloadable case-study PDFs when ready.
- Add only verified project outcomes and metrics. The employee-engagement and recruitment items are currently described as portfolio studies/process exercises, consistent with the supplied CV.
- If you want to add a CV download, place your PDF in this folder and add a link to it in the HTML.

## Design
Soft white, light blush pink and peach palette; editorial typography; responsive project sections; accessible navigation labels; reduced-motion support.
